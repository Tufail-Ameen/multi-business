# multi-business

POS frontend (`react-invoice-app`) and backend (`node-learning`) in one repo.

## Start

```bash
npm install
npm run install:all
npm run dev
```

- Backend: http://127.0.0.1:5001
- Frontend: http://localhost:3000

Copy each app's `.env.example` to `.env` before the first run. Do not commit `.env` files.
